Alpha es un analizador cuantitativo multiactivo diseñado para detectar oportunidades de trading en tiempo real.  Procesa indicadores técnicos como RSI, Medias Móviles, fuerza de tendencia  y volumen para calcular porcentajes de confianza, definir niveles de entrada, Stop Loss y Take Profit, e identificar la huella de acumulación/distribución.
